# Stok nol memblokir penjualan

Kalau stok sebuah produk 0, aplikasi menolak menambahkannya ke transaksi. Kasir harus mengisi stok dulu lewat layar produk. Stok tidak pernah boleh menjadi negatif.

Alternatif yang ditolak: membiarkan stok minus sebagai sinyal bahwa catatan stok tidak akurat. Ditolak karena pemilik toko memakai angka stok untuk memutuskan belanja, dan angka minus membuat laporan stok tidak bisa dipercaya.

Konsekuensi: kalau data stok di lapangan ternyata lebih banyak dari catatan (misal barang masuk belum diinput), kasir terhalang menjual sampai stok diperbaiki. Itu disengaja — lebih baik memperbaiki catatan daripada menjual barang yang sistemnya bilang tidak ada.
